Short, practical guides. Tap a title to open it.

How to start using an AI tool
  1. Pick one tool and create a free account.
  2. Start with a small task, like rewriting an email.
  3. Review the answer and ask follow-up questions.
  4. Check facts before you rely on them.
How to write better AI prompts
  1. Say who you are or the role you want it to play.
  2. State the task clearly.
  3. Add context: audience, length, tone.
  4. Ask for a format, such as a table or bullet list.
How to improve your productivity
  • Write your top three tasks each morning.
  • Work in 25-minute focus blocks with short breaks.
  • Batch similar tasks, like replying to messages.
  • Automate repeat work when a tool can do it.
How to manage and track links
  1. Create a short link for each place you share, such as WhatsApp Status or a social post.
  2. Add UTM tags (source, medium, campaign) so analytics show where visitors came from.
  3. Use a link tool such as Dub to view clicks.
  4. Compare results and keep what works.
