# Tharun Tech Hub
Static site (HTML/CSS/JS). Edit content in `build.py`, then run `python3 build.py`, or edit the .html files directly.
Contact form: sign up at formspree.io, then put your endpoint in `data-endpoint` in contact.html (and build.py).
When approved, add affiliate links as `<a href="YOUR_LINK" data-aff>`; the script adds rel="sponsored".
